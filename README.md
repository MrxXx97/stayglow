# PhotoBoost 🚀

**AI-Powered Property Photo Enhancement Platform**

Transform your Airbnb and real estate photos instantly with AI. Get professional-quality results that increase bookings by 32% and boost rental value by 40%.

## ✨ Features

- 🎨 **AI-Powered Enhancement** - Instant photo transformation
- ⚡ **Lightning Fast** - Results in seconds, not hours
- 🎯 **Professional Quality** - No expensive equipment needed
- 📸 **Multiple Options** - Brighten, enhance colors, upscale, and more
- 💰 **Flexible Pricing** - Free tier + Pro subscriptions
- 🌙 **Dark Mode** - Beautiful dark theme support
- 📱 **Responsive** - Works on all devices

## 🚀 Quick Start

### Prerequisites

- Node.js 20+
- npm or pnpm
- Supabase account (for database and storage)

### Installation

1. **Clone and install dependencies:**

   ```bash
   npm install
   ```

2. **Set up environment variables:**
   Create a `.env.local` file:

   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_key
   ```

3. **Run development server:**

   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Database**: Supabase (PostgreSQL)

- **Auth**: Supabase Auth
